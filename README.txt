MobileRef V1.3 — 画像全体表示・ズーム改善版

【Macで試す】ZIPを解凍し、index.htmlをChromeまたはSafariで開く。
「＋ 画像」で複数選択し、画像をドラッグして配置。「保存」で.mrefを出力し、「開く」で読み込む。
ローカルファイルで一時保存・クリップボード・全画面等が制限される場合はHTTPS公開版を使用する。

【GitHub Pages】新規リポジトリのルートに index.html、manifest.webmanifest、sw.js、icon-192.png、icon-512.png をアップロードし、Settings > Pages > Deploy from a branch > main / (root) を選択。
公開URLをMac/Android/iPadで開く。Android Chrome、iPad Safariではホーム画面追加を利用可能（実機検証が必要）。一度オンラインで開いてキャッシュが完了した後はオフライン起動を想定。

【操作】画像ドラッグで移動、選択画像の青い角をドラッグで拡大縮小、空白ドラッグでキャンバス移動、ホイールまたは2本指でズーム。下部のボタンで画像編集。Cmd+S 保存、Cmd+Z 元に戻す、Shift+Cmd+Z やり直し、F 全体表示、Delete 削除。

【ファイル】.mref はバージョン付きJSONに画像をBase64で内包する自己完結形式。ZIP形式ではない。画像を外部サーバーにアップロードしない。Google Drive等で手動受け渡し可能。PureRef .pur 非対応。ファイル容量は元画像より概ね増加する。

【制約】Web画像の取り込みはサイトのCORS制限やブラウザのドラッグ・クリップボード対応に依存。失敗時は画像を端末に保存して読み込む。iPadの全画面、ファイル保存、タッチ、オフライン動作は実機未検証。スマートフォン最適化・自動同期なし。ブラウザ一時保存に頼らず.mrefを保存すること。

【V1.1の変更】URL入力・白黒変換ボタンを削除。Web画像のドラッグ＆ドロップ用取得処理は維持。既存.mrefの形式および白黒表示情報は互換性のため維持。
【検証】JavaScript構文・ボタン参照の静的検証済み。V1.1の実機動作は未検証。

【V1.3】画像をダブルクリック／ダブルタップ、または「画像全体」で画面に合わせる。再度同じ操作またはEscで元に戻る。ホイールズーム感度を調整。既存.mref形式は維持。

【V1.3】全選択（⌘A）、複数選択（Shiftクリックまたはボタン）、グリッド整列、幅・高さ統一（青い基準画像、回転前寸法、縦横比維持）。追加画像は一括選択し、既存画像と重なる場合は右側に配置。複数選択モード解除後に一括ドラッグ。
